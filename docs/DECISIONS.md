# Decisions

One line each, newest first: date · decision · why.

- 2026-11-09 · Web app on classic Cloudflare Pages (`commish-2o8.pages.dev`, created with `--force`) · wrangler 4.152 routes `pages` commands to Workers-based Pages, which failed without a config; classic Pages is what the runbook and Joe's go-ahead named, and `_redirects` already handles deep links
- 2026-11-09 · Worker CORS allows only the Pages origin; local dev sets `ALLOWED_ORIGINS=*` in `.dev.vars` · CORS isn't access control (rate limits are), but it keeps other sites from spending the demo root's NEAR through visitors' browsers
- 2026-11-07 · Redeployed as `commish-v2.commishhq.testnet` (vault prefix `cmsh2-`) · the config pins the job hash and has no setters, and the job hash changed (reproducible build) along with the security fixes; `commish.commishhq.testnet` stays as the Day-0 spike evidence
- 2026-11-07 · `league` votes need a quorum of a majority of the league's teams (≥ 2), set at vault creation · an independent security review showed that with quorum 2 the commissioner plus one approved sock-puppet account could pass a transfer immediately. Spec 7.5 said "majority by role weight"; flagged to Joe
- 2026-11-07 · `approve_claim` names the account being approved · a claim that slips in before the approval can't be approved by mistake
- 2026-11-07 · Dues must cover what the team owes in one payment; smaller payments are returned · otherwise a 1-unit payment from anyone locks a new league's rules
- 2026-11-07 · Unknown rosters in a result are recorded and their payouts withheld, instead of rejecting the result · a roster list that doesn't match Sleeper would otherwise block every week and the season
- 2026-11-07 · Season isn't blocked by a week that failed with NO_SCORES · such a week can never settle
- 2026-11-07 · Vault proposal period 180 days (spec: 14) · a payout must not expire before anyone finalizes it
- 2026-11-07 · `finalize` approves at most 3 payouts per call; settle callbacks carry a request nonce; vault names get a random suffix; league ids are range-checked · gas safety for big ties, no duplicate proposals from a late callback, no vault-name squatting
- 2026-11-07 · Enclave job built by scripts/build-job.sh: rustc pinned to 1.98.1, machine paths remapped · the wasm embedded /Users/… registry paths, so other machines got a different hash; two builds from different checkouts and CARGO_HOMEs now match (71854dd1…)
- 2026-11-07 · Web reads through a failover RPC (FastNEAR, then rpc.testnet.near.org) · one 408 from an RPC during testing
- 2026-11-07 · Worker adds `POST /sponsor` (not in the spec): sends one vault deposit to a quick account that creates a league; 1 per IP and 3 total per day · a vault costs ~5.4 testnet NEAR and quick accounts get 0.5, so "Start a league" would otherwise dead-end for a judge
- 2026-11-07 · The Worker signs only account creation, faucet mints, sponsorship, and (admin-only) demo seeding · the demo reset needs 12 team accounts to claim and pay; their keys are made and dropped during the reset
- 2026-11-07 · Demo seeding pre-settles weeks 1–2 · the feed shows real Paid receipts a judge can open and check before pressing anything
- 2026-11-07 · Payouts are released by any signed-in viewer once the hold ends (demo: any viewer; real leagues: members) · `finalize` is permissionless, and the Worker must not sign settlements
- 2026-11-07 · Season projection on the league page reserves unsettled weekly prizes · matches the season-after-weeks rule and the create-screen summary
- 2026-11-07 · 1Click preview quotes credit a placeholder Intents balance (`recipientType: INTENTS`) · testnet accounts don't exist on mainnet and DESTINATION_CHAIN quotes to a missing account fail
- 2026-11-07 · NearBlocks isn't used for receipts · its v1 API was retired 2026-11-05; the receipt takes the request tx from OutLayer's attestation and payout status from the vault
- 2026-11-07 · Season settles only after every regular-season week has settled (when weekly payouts are on) · the spec's base (vault balance minus payouts on hold) would otherwise let an early season payout eat unsettled weekly prizes; ordering keeps the "$70 weekly · $530 split" promise. Flagged to Joe
- 2026-11-07 · `league` role votes need quorum 2 on top of majority · without it a league whose only member is the commissioner lets the commissioner pass a transfer alone (dues can arrive before claims are approved)
- 2026-11-07 · `finalize` re-reads the pot and registers the winner with the token before approving · testnet's Sputnik DAO (v2.0.0 era) marks a proposal Approved even when its transfer fails, so the contract makes failure impossible instead of detecting it
- 2026-11-07 · Vault deposit 5.3 NEAR · measured: a DAO from sputnik-v2.testnet locks 4.72 NEAR (471,686 bytes); 0.58 NEAR left for ~50 proposals
- 2026-11-07 · Sandbox tests use the exact testnet bytes of sputnik-v2.testnet (factory + DAO) and outlayer.testnet (fixtures/wasm/) · the testnet factory is older than the repo; testing anything else would test the wrong code
- 2026-11-07 · near-workspaces 0.23 for sandbox tests, with rustls pinned to 0.23.40 in dev-deps · near-sdk 5.29's unit-testing feature pins aws-lc-rs 1.16.2; rustls 0.23.46 needs ^1.18
- 2026-11-07 · near-sdk 5.29.1, not 5.30.1 · 5.30.1 was two days old
- 2026-11-07 · OutLayer source = WasmUrl on FastFS, pinned by SHA-256; contract stores sha256(output) and the OutLayer request id · verified: equals the attestation's output_hash; receipts link /attestations/by-request/{id}
- 2026-11-07 · The job embeds an `outlayer.manifest` allowlist (api.sleeper.app only) · the worker enforces it and it's covered by the pinned hash
- 2026-11-07 · Canonical JSON = RFC 8785 (JCS) with ECMAScript number formatting via Ryū · Sleeper sends 9.0; Rust and JS print it differently; Rust's {:e} also misses one RFC vector. Fuzzed against Node: 0 mismatches in 299,938 doubles
- 2026-11-07 · Points → hundredths by rounding the decimal value half away from zero · binary float × 100 turns 162.385 into 16238; same result on all real (2-decimal) data
- 2026-11-07 · Finality uses `leg` (fallback `week`), `season_type == "post"` counts as past, "Tuesday after week W" from `season_start_date` · S3
- 2026-11-07 · Demo league: Armchair Football League (Sleeper 1197787383500648448, 2025) · public, complete, 12 teams, bracket with a 3rd-place game, clean team names
- 2026-11-07 · Testnet root `commishhq.testnet` (new, faucet-funded); contract `commish.commishhq.testnet`, token `usdc.commishhq.testnet`, vaults `cmsh1-<id>.sputnik-v2.testnet` · Joe asked for a fresh root
- 2026-11-07 · Browser "Check the math" runs settle-core compiled to wasm32-unknown-unknown with plain exports (no wasm-bindgen) · same source as the enclave, no extra tool to install
- 2026-11-07 · Wallet: @hot-labs/near-connect + near-connect-hooks + near-api-js 7, per the near-dapp agent skill · `npx skills add` was blocked here, so the skill files were read from github.com/near/agent-skills
- 2026-11-07 · Sleeper first, Yahoo later · Sleeper's API is public and read-only with no key; Yahoo needs OAuth
- 2026-11-07 · League money sits in a Sputnik DAO per league · Social Money track asks to build on Sputnik DAO; no single person can withdraw
- 2026-11-07 · Testnet only; 1Click shown as dry-run preview · hackathon allows testnet; avoids real-money gambling questions
